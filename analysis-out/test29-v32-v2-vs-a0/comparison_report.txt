CONCLUSION
Same physical motor, same jig, same clamp, no remount, 32 minutes apart, ONLY the
sector changed (both runs use the reversal-based approach -- V2 has ReversalCount=1,
A0 has ReversalCount=2, a residual confound worth noting but far too small a
difference in kind to explain a 0/10 -> 10/10 ClosureValid flip and a >4x residual
change on its own -- V3.2's A0-vs-B already showed reversal count changes move
residual by <40%, not >400%).

Closure: V2 fails outright (0/10, ~-0.35deg, limit is +/-0.20deg) -> A0 passes cleanly
(10/10, ~-0.02deg). Residual: V2 ~0.27deg -> A0 ~0.086deg (>3x better).

This is now a DIRECT, single-session, single-motor confirmation (not an indirect
historical-baseline comparison): sector is the dominant driver of P03's Closure/
residual problem, not reversal-vs-no-reversal (already ruled out by V3.2) and not
day-to-day/build/thermal variation (ruled out by running both in one sitting).
