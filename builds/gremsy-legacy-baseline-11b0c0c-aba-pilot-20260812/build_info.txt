SAME physical mount as `tools/dist/captured-logs/S4-P03-JIG8-remount01-
openloop-v1-run02.txt` (P03/JIG8/remount01, not yet disturbed), run one

is NOT zero -- ALG-001's fix and the RawP2P-vs-RobustP2P primary-metric

changes (i.e. same physical curve shape/extrema/harmonics, with the reported

the numbers match exactly.
